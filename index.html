📖 使用说明

• 闭环：录入错题 → 标错因/知识点 → 系统按艾宾浩斯安排 6 次复习（当天/1h/1d/3d/7d/30d）→ 复习答对推进，答错重来 → 全对标记「已掌握」。
• 五层追因（手填辅助）：错在哪步 → 属哪个知识点 → 不会/不熟/会用但错 → 根因在哪个年级 → 不补会影响什么。
• 蒙题检测：蒙对的题单独标记，复习时优先验证，避免「假会」。
• Boss 战：针对薄弱知识点出 3 道变形题（基础+50/进阶+100/综合+200XP），全对通关。
• 费曼讲解：选一个知识点，用自己的话讲一遍并自评，讲对 +100XP、掌握度升 A。
• 游戏化：XP 累积升级（青铜→王者13级），解锁成就。数据可一键导出交爸爸/同步到 IMA 知识库。
• AI 增强：本工作台离线自填；需要 AI 自动识别题目/出题时，把导出的 JSON 或截图交给 WorkBuddy / ima 处理后再回填。

📱 手机 / 离线部署（PWA）

本工作台是单文件网页。想在手机上当 App 用、断网也能开：
① 电脑上进入文件所在目录，运行 python -m http.server 8000；
② 手机与电脑连同一 WiFi，浏览器打开 http://电脑IP:8000/罗舜_学习工作台.html；
③ 点浏览器「添加到主屏幕」，即成为一个离线 App（已配 manifest + service worker 缓存）；
④ 数据在本浏览器本地；若要在多设备间同步，请点右上角「🔐 登录同步」（手机号验证码登录，云端按账号隔离）。
